# Calculadora-Laboral-y-Financiera-RD
Calculadora laboral y financiera para República Dominicana: sueldo neto con AFP/ARS/ISR configurables, presupuesto por período (mensual/quincenal/semanal), vacaciones, regalía pascual, feriados y más. Bilingüe ES/EN, tema día/noche y guardado local. HTML/JS puro, sin dependencias.
